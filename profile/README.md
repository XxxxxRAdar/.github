# XxxxxRAdar

Radar-producten: tools die openbare informatiestromen volgen, matchen aan een bedrijfsprofiel en dossiers voorbereiden.

- **[radar](https://github.com/XxxxxRAdar/radar)**: de monorepo. `apps/tenderradar` (aanbestedingen), `apps/subsidieradar` (subsidies, te starten), gedeelde `packages/`.
- Structuur en afspraken: [radar/docs/STRUCTUUR.md](https://github.com/XxxxxRAdar/radar/blob/main/docs/STRUCTUUR.md).
- Werkwijze: branch per wijziging, PR naar `main`, `main` is altijd deploybaar.
