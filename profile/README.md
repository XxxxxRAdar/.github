# XxxxxRAdar

Radar-producten: tools die openbare informatiestromen volgen, matchen aan een bedrijfsprofiel en dossiers voorbereiden.

- **[tenderradar](https://github.com/XxxxxRAdar/tenderradar)**: Belgische en EU-aanbestedingen (e-Procurement, TED), signalen uit besluiten, gunningen en aflopende contracten. Eigen repo.
- **[radar](https://github.com/XxxxxRAdar/radar)**: huis voor SubsidieRadar en volgende Radars, met gedeelde `packages/`. Structuur en afspraken: [docs/STRUCTUUR.md](https://github.com/XxxxxRAdar/radar/blob/main/docs/STRUCTUUR.md).
- Werkwijze overal: branch per wijziging, PR naar `main`, `main` is altijd deploybaar.
